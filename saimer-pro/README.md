# S'aimerプロダクション サンプルサイト

デザイン・構成確認用の静的サイトです。HTML / CSS / JavaScriptのみで構成しています。

## 公開前に必要な差し替え

- ヒーローの空画像
- 4名分の正式な人物写真（各2枚以上）
- 英字氏名とURLスラッグの確認
- プロフィール、紹介文、出演歴
- 事務所・各タレントの公式SNS URL
- 事務所理念とプライバシーポリシーの最終文面
- OGP画像、公開ドメインに合わせたcanonical / sitemap / robots設定

サンプル人物写真は1枚のスプライト画像です。正式素材への差し替え時は、各写真を独立ファイルとして配置してください。
