# 一覧の画角統一と髙島 大幹の写真差し替え

2026-10-22のユーザー指示：石原 月斗の一覧写真を基準に人物の大きさを揃える。髙島は支給の9250.jpgへ変更し、詳細ページにも反映する。

石原の既存一覧写真は維持し、中山・月形・髙島の頭頂から顎までの高さをカード高さの約48%、頭上余白を約7%に合わせた。以前の記録にある63%は旧ツールの基準点による数値で、今回の頭頂・顎の測定とは異なる。髪型・顔立ちによる横幅の違いは維持。月形は左端からの切り抜きで、撮影範囲内に収める。

対象はトップの4名カードと所属一覧。詳細写真は今回髙島のみ差し替え、支給写真の2:3の全体を維持。写真拡大とPerson構造化データも新しい画像URLへ変更。

中山・月形はリポジトリの960px版を元に切り抜いた。髙島は今回の支給原本1024×1536pxを元に、一覧用と詳細用をそれぞれ生成。色・人物・背景の生成や加工は行わず、構図調整とWeb配信用縮小のみ。切り抜き後の画素数を超えないよう、最大幅は中山640px・月形636px・髙島468pxとし、srcsetの幅記述とHTML寸法も実寸に合わせた。全候補にWebPとJPEGを用意し、公開用からメタデータを除去。

原本のSHA-256、座標、生成画像寸法・ハッシュは同名JSONに記録。9250.jpg原本は変更していない。新画像は20261022の別名とし、旧画像キャッシュを回避。髙島の画像台帳はportrait-assets.jsonを更新。原本は公開リポジトリへ格納しない。

既存のnormalize-card-portraits.pyとoptimize-portraits.pyは旧命名・基準点を前提とする。次の写真差し替え時は、最新HTMLと今回のJSONを参照して対象の全サイズ・WebP/JPEG・拡大リンク・SEOを揃えて更新する。

検証：npm run test:allが通過。生成画像の実寸・メタデータ・srcset記述を照合し、比較画像で4名の画角を確認。公開前のスマートフォン・デスクトップ表示はGitHub Actionsの既存ブラウザ検査で確認する。
