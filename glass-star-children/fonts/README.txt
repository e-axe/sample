LP Mincho: Noto Serif JP Regular (400)
LP Gothic: Noto Sans JP Regular (400)

These are WOFF2 subsets of the Google Fonts CSS API's regular TTF fonts.
They include all text currently present in index.html, basic Latin,
Japanese kana and punctuation. The original font names are retained.

SIL Open Font License 1.1: see the accompanying OFL.txt files.
Download sources and original SHA-256 hashes: sources.json.

Rebuild after adding text with scripts/build-lp-fonts.py.
The page uses same-origin font files; it does not contact Google Fonts.
There is no runtime JavaScript font loader or additional build dependency.
