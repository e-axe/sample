# UI/UX再レビューと最新の修正（2026-11-06 JST）

この記録を、同日の以前の修正記録・引き継ぎ文内の異なる指定より優先する。公演・出演回・役名・氏名・画像番号の正本は変更していない。

## 反映内容

- ヘッダーをPC・スマホとも追従。アンカーにヘッダー分の余白を確保。PC幅へ戻した際のモバイルメニュー状態も閉じる。
- キャストの5ブロックと単独・ペア・3名の19単位、正式順、全員常時表示を維持。各単位を同じブロック内で横に配置し、縦の長さを短縮。ブロック間の罫線と出演回リンクの囲み線を撤去。
- 中央の画像は新規生成した劇場イメージに差し替え。以前の斜めの見せ方に寄せ、マイク・台本画像とCSSだけのぼかし案を撤回。原画・プロンプト・配信画像は `image-generation.md` を参照。
- メイホリックの支給公式ロゴをフッターへ掲載。透明余白除去と縮小のみで、可逆WebPを使用。
- 日程表を検索欄の直下、結果を日程表のすぐ下へ配置。「現在の選択」で日時・出演者を表示。「日時を解除」「出演者を解除」を別々に設置し、結果欄では「条件をすべて解除」を表示。
- 選択時刻に「選択中 ✓」を表示。再度同じ時刻を押すと日時のみ解除。出演者条件は保持し、出演なしの回は無効のまま。
- 日程表の操作で結果へ自動スクロールする動作を撤去。結果一覧内で公演を絞るときのみ結果へ移動。解除後のフォーカスを有効なコントロールへ戻す。
- 一覧が閉じたままの公演について、19名分の写真・氏名DOMを生成しない。最大9回×19名の生成を回避。展開時に一度だけ生成。イベントの委譲・公演別配役の再利用・断片への一括挿入を使用。
- 無限の背景光アニメーションを一回に限定。出演者全行をスクロール監視する処理を撤去。本文は常時表示、動きを減らすCSSを維持。新たな外部依存・フォント・追跡コードは追加していない。
