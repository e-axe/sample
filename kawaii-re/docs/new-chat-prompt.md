**デザイン・掲載内容**

- 採用済みの白・ピンク・シアン、斜めの構成、華やかで洗練された雰囲気を基本にしてください。正式ロゴを必ず使用し、独自に描き直さないでください。
- キャストは最初から全36名を見せてください。折りたたみや「もっと見る」は不要です。
- キャストは正式詳細とユーザー指定の掲載順と単位を維持してください。`content.json` の `billingGroups` に19単位・5ブロックで保持しています。単独・ペア・3名の単位を守り、同じブロック内は横に並べて縦の長さを抑えてください。
- キャスト写真は丸枠。延松舞佳、岡本芽子、村星りじゅを含め、顔が枠で切れないように人物ごとに調整してください。顔を生成・加工せず、公式宣材原本から位置と範囲を調整してください。
- あらすじは畳まず、正式な全文を最初から見せてください。
- STORYには新規生成した `assets/story-theatre.webp` を斜めに表示してください。マイク画像とCSSだけのぼかし案は撤回されました。劇場・FAQ下部には以前の舞台画像を使用してください。
- あらすじのピンクの導入文とLIVE×Readingの説明文、要点の色・太字を維持してください。ボタン等は丸く、背景はごく淡いグラデーション。ヒーローは以前の広い斜め構図を基準に調整しています。
- 選択公演は日付・開演時刻の帯、選択中ラベル、丸写真・名前・役名で表示。検索した方はピンク枠で強調し、結果内のボタンからも公演を選択できます。
- 色使いや全体の雰囲気は維持し、細い・小さい文字をほんの少し読みやすくしてください。あとで戻す可能性があるので、文字の大きさ・太さは調整しやすく管理してください。現在は `type-tokens.css` で管理しています。
- ヒーローセクションに上演時間の記載はいりません。上演時間は日程・FAQに掲載してください。
- 「会場」ではなく「劇場」と表記してください。劇場地図は埋め込み、別画面で地図を開くリンクも残してください。
- メイホリックの公式X https://x.com/mayholictheater を追加してください。SNSや外部リンクはアイコンと文言で用途が分かるようにしてください。
- デザインコンセプトを崩さない程度の、小さな動きを実装してください。情報を読む邪魔をせず、動きを抑える端末設定にも対応してください。

**不具合とUXの修正要件**

- 「出演回を見る」の結果は検索欄・日程表のすぐ下に表示し、押したあとに何が変わったのか、どの回に出演するのかがすぐ分かるようにしてください。
- 日時を選んでも、選択した出演者の条件を勝手に解除しないでください。出演しない回は「出演なし」と明示し、選択不可にしてください。取り消し線で完売や中止のように見せないでください。
- 768px前後で文字が背景に重なる問題と、PCで横スクロールが出る問題を解消してください。スマホ・タブレット・PCで文字と背景を安全に分けてください。
- 応援キャストの選択と実際の出演は別であることが、購入前に読めるようにしてください。予約成立後の取消し・払い戻し・公演変更不可の要点も、販売ボタンの直前へ常時表示してください。
- 発売前・発売後・公演終了後の表示を適切に切り替えてください。実際の残席や販売状態を取得していないのに「販売中」と断言しないでください。
- スマホの固定ボタンは、同じ導線が画面内にあるときや日程セクション内で重複して邪魔にならないようにしてください。
