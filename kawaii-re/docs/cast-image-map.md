番号は固定IDです。並びを変更しても振り直さず、差し替える人物の番号を維持してください。初期割当は正式詳細の掲載順です。

## 差し替え手順

1. 下表で出演者と番号を照合する。
2. 同じファイル名の画像を更新する。人物の変更がなければ番号は維持する。
3. 原本や切り抜き位置が変わる場合は、`content.json` の `source`・`crop` を更新する。
4. ビルド・整合性チェック後、丸枠で顔が切れないことを目視確認する。
