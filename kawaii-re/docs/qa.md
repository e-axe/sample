## 検証方法

組み込みブラウザー（IAB）でローカル版とGitHub Pages版を確認。Playwrightへのフォールバックは使用していない。ブラウザーのスクリーンショットで比較し、採用モックと最終画像の両方を画像ビューアーで再確認した。

画面幅：1440px、採用モックのPC領域に相当する878px、390px、320px。モックはPCとスマホを並べた画像なので、PC領域幅を比較対象とした。320pxで横方向のはみ出しなし。Safari・実機iPhone/Androidは未検証。

ローカルの比較画像は作業フォルダ `design/desktop-final.png`、`design/public-desktop.png`、`design/public-mobile.png`。一時的なデバッグ用スクリーンショットは公開ソースに含めない。

## 採用デザインとの比較

基準画像：[採用モック](approved-mock.png)

| 比較点 | 結果・対応 |
| --- | --- |
| 公式ロゴ | 支給原本から透明WebPを作成。縦横比の崩れを検出して修正 |
| ヒーロー | PC左情報・右舞台、斜め境界を保持。スマホは背景とロゴ→情報の順 |
| コピー | ライブ訴求、歌声のコピー、日程、会場、脚本・演出、CTA、発売案内を保持。追加のヒーロー見出し・バッジなし |
| 配色と見出し | 白地、ピンク、シアン、明朝の公演情報・斜体英字見出しを保持。文字コントラスト用のピンクは濃く調整 |
| 写真 | 丸型・PC6列・スマホ2列。支給35名を配置し、顔切れを見つけた写真を再調整 |
| 情報の順序 | STORY→CAST→日程・券種→VENUE/FAQの構成を保持 |
| 予約導線 | 黒いCTA、出演回を確認する導線、スマホ固定ボタンを実装 |
| 余白・密度 | 正確な情報とタップ領域を優先し、文字と余白を実サイト向けに調整 |

採用モックの構成・意匠を引き継いだ実装として照合済み。ピクセル単位の複製ではなく、以下の差分を意図的に採用している。

- 背景はモックに沿って生成した独立イラストのため、花・吊り飾りなどの細部に作画差がある。公式ロゴ・人物には生成を使っていない。
- 仮キャストを正式宣材へ差し替え。吉武千颯さんのみ素材未提供のため仮画像と「写真準備中」。
- 正式な全36名、19役、券種特典、購入注意事項を反映し、全員の展開・あらすじの続き・検索結果を追加。
- 出演者から探す操作は、実用性・キーボード操作のためネイティブ選択欄で実装。
- 本番と区別するためフッターに見本の表示、検索向けにnoindexを設定。

## 動作・整合性

| 確認 | 結果 |
| --- | --- |
| タイトル・本文・エラー表示 | 正しいページが表示され、白紙・エラー画面なし |
| コンソール | ローカル・公開ページで関連エラーと警告なし |
| 出演回 | 公式11/5役別表を独立に転記した検証データと照合。36名・9公演・毎回19役が一致 |
| 出演者から検索 | 相良茉優→12/17・18の4公演。公開サイトでも同じ結果 |
| 公演から確認 | 第9回→12/20 17:00、出演19名。汐入あすかを含み相良茉優は含まない |
| 一覧展開 | 全36名のカードへ展開し、各出演回への導線を確認 |
| スマホメニュー | 開閉、会場への遷移後に閉じることを確認 |
| FAQ | 差し入れの項目を開いて本文を確認 |
| 発売前 | 販売リンクは無効で発売日時を案内 |
| 発売後 | 隔離したローカル検証タブの仮想時刻を進め、カンフェティURLと販売案内へ切替を確認。終了後タブを閉じて通常状態へ復帰 |
| JavaScript無効 | 公演概要・日程表・各キャストの全出演日時が読めることを確認 |
| 画像・リンク | ローカル参照先の存在を検証。公開先でロゴ・背景・宣材の表示を確認 |

検証コマンド：`node tools/build.mjs`、`node tools/check.mjs`、`git diff --check`。

GitHub Pagesの[初回デプロイ](https://github.com/e-axe/sample/actions/runs/42052034170)は成功し、公開ブラウザーでも表示・検索を確認済み。ローカルHTTPクライアントは公開先への接続が切断されたため、公開確認にはブラウザーとGitHubの配信結果を使用した。

実際の購入・決済は実施していない。発売前のカンフェティ販売画面、残席情報、未発表アフターイベントと開場時刻は検証対象外。
