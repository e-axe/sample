## 目的と成功条件

予約前のお客様が、作品の魅力・出演回・日時・会場・券種を迷わず理解し、正しい公演を選んで公式販売先へ進める公演サイト。作品の売りであるライブパフォーマンスを最初の画面で伝える。

見本公開先は `https://e-axe.github.io/sample/kawaii-re/`。GitHub `e-axe/sample` の直下 `kawaii-re` で管理する。今回の公開対象はクライアント向け見本。検索登録を避ける `noindex,nofollow` を指定し、本番ドメインへの展開は別工程とする。

## 情報設計・予約導線

- ロゴ → 公演日程と会場 → 日程・チケットの順で一目で分かる。
- キャストカード → 検索欄・日程表のすぐ下に出演公演 → 公演の出演者を確認 → 券種と常時表示の購入注意事項 → カンフェティ。出演者の条件は日時選択でも保持し、出演しない回は「出演なし」として無効にする。
- 日時から探す場合も、各回の出演者を確認できる。
- 応援キャストの選択は出演の保証ではない。購入前の出演日確認を券売導線の近くへ置く。
- 発売前は予約できると誤認させない。JSTの発売日時で販売導線を切り替え、発売後もページ復帰時に更新する。完売・残席はAPIがないため表示しない。
- 特典・購入後の取消変更不可・差し入れ受付不可など、正式に発表された注意事項をFAQと購入箇所に掲載する。
- 主題歌は公式配信先へのリンク。動画・自動再生・未提供のメディアは作らない。

## 実装と保守

- GitHub Pages向け静的HTML/CSS/JavaScript。依存パッケージなし。主要情報・全キャスト・公演表をHTMLに出力し、JavaScriptがなくても読める。
- `content.json` が公演・出演回の正本。`tools/build.mjs` がHTMLを生成。生成済み `index.html` を直接直して正本と乖離させない。
- `styles.css` がデザイントークン・レスポンシブ、`app.js` がメニュー・出演回検索・公演選択・発売状態を担当。
- 画像はローカル配信のWebP、幅高さを予約、ヒーロー以外は遅延読込。日本語フォントは必要文字に絞ったWOFF2を同一オリジンから配信し、外部フォントサーバーへの閲覧時通信とトラッカーは追加しない。劇場地図はユーザー指定によりGoogleマップを遅延埋め込みする。
- 320px幅以上、キーボード操作、見えるフォーカス、読み上げ用ラベル、状態通知、動きの抑制に対応。
