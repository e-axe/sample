# kawaii-re の作業方針

- 作業前に `docs/production-brief.md` と `docs/sources.md` を読む。
- 採用済みモックが基準。公式ロゴ原本と支給宣材を使用し、独自ロゴへ変更しない。
- 最新の公式公演情報を `content.json` に反映後、`node tools/build.mjs` で生成する。
- 出演日、料金、発売日時は公式資料で確認。応援キャストと出演者を混同しない。
- 見本公開先は `/sample/kawaii-re/`。本番として検索登録する変更は別途指示を確認する。
- 同じリポジトリの他サイト・デプロイ設定を変更しない。
- 公開前にビルド、出演回整合性、PCとモバイルの表示・主要導線を確認する。
- 未確定情報を補完しない。素材原本と作業用データを区別する。認証情報や期限付ダウンロードURLを記録しない。

- キャスト36名とあらすじ全文を常時表示する。出演者は `content.json` の `billingGroups` に従い、単独・ペア・3名の19単位と5ブロックを維持する。同じブロック内の単位は横に並べてよい。PCで19行に固定せず、単位の途中で改行しない。ブロックの区切り線は不要。
- ヒーローに上演時間を再追加しない。表示上の呼称は「劇場」。
- 画像は固定番号で管理し、差し替え時は `docs/cast-image-map.md` を照合する。
- 日時選択で出演者の条件を勝手に解除しない。検索結果は検索欄・日程表のすぐ下。日時のみ／出演者のみ／全条件の解除を区別する。
- `docs/new-chat-prompt.md` のユーザー指示と `docs/revision-20261106.md` の検証結果を参照する。
- STORYは新規生成した `assets/story-theatre.webp` を斜めに表示する。マイク画像・ぼかした既存画像のCSS代用は撤回。劇場・FAQ下部は以前の舞台画像。あらすじのピンクの導入・強調、丸いボタン、淡いグラデーションを維持する。

- ヘッダーはPCを含め追従。アンカーの移動先が隠れないことを確認する。
- 企画・制作の公式ロゴは `assets/mayholic-logo.webp`。支給PNGの透明余白除去・縮小のみで、描き直さない。
- 2026-11-06の最新状態は `docs/ux-review-20261106.md` を優先する。
