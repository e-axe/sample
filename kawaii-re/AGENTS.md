# kawaii-re の作業方針

- 作業前に `docs/production-brief.md` と `docs/sources.md` を読む。
- 採用済みモックが基準。公式ロゴ原本と支給宣材を使用し、独自ロゴへ変更しない。
- 最新の公式公演情報を `content.json` に反映後、`node tools/build.mjs` で生成する。
- 出演日、料金、発売日時は公式資料で確認。応援キャストと出演者を混同しない。
- 見本公開先は `/sample/kawaii-re/`。本番として検索登録する変更は別途指示を確認する。
- 同じリポジトリの他サイト・デプロイ設定を変更しない。
- 公開前にビルド、出演回整合性、PCとモバイルの表示・主要導線を確認する。
- 未確定情報を補完しない。素材原本と作業用データを区別する。認証情報や期限付ダウンロードURLを記録しない。
