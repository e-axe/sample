## 実装

承認済み1536×1024pxの原画を再生成せず、PC1536×1024 / 1920×1280px、スマホ640×569 / 800×711pxのWebPへ出力。最大PC191,672 bytes、スマホ89,954 bytes。1920px版は通常の補間拡大。マスク・スーツ布の造形や配色を追加変更しない。

PCは右側画像の枠を縦横比に合わせ、左端をCSSのマスクで背景へなじませる。スマホは原画右側1152×1024pxを切り出し、画像枠の高さを幅に応じて調整。新規ファイル名、picture/srcset、preload、alt、CSSハッシュ、ビルド元を同期。正式公演情報JSON、JS、公式ロゴ、他セクションのHTML・素材は元版と一致。
